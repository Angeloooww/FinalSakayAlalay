# ERD for FinalSakayAlalay

This folder contains a PlantUML diagram representing the main Firestore collections and relationships used by the app.

- `project_erd.puml`: PlantUML source for the database ERD.

How to render the diagram

- Using PlantUML locally (requires Java + Graphviz):
  1. Install Java and Graphviz.
  2. Install PlantUML (or use `plantuml.jar`).
  3. Run:

```
java -jar plantuml.jar assets/erd/project_erd.puml
```

- Using an online PlantUML server: copy the contents of `project_erd.puml` into an online PlantUML editor (e.g. https://plantuml.com/plantuml) or use a PlantUML viewer extension in VS Code.

Notes and assumptions

- The ERD was generated by scanning the codebase and inferring schema fields used by Firestore reads/writes.
- Primary collections discovered: `users`, `pwd_users`, `pao`, `pao_locations`, `pwd_notifications`.
- Timestamps are stored with `FieldValue.serverTimestamp()` in many writes.
- `users` acts as a small routing table (role lookup) pointing to either `pwd_users` or `pao` documents with the same UID.
